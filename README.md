## 🚀 Featured Projects

**Cloud Security**
* **[HIPAA AWS Security Checker](https://github.com/markthedev12/hipaa-aws-checker)**: Read only Python CLI that audits AWS accounts across S3, IAM, CloudTrail, KMS, VPC, and RDS, with every finding mapped to a HIPAA Security Rule control.
* **[AWS RDS Secure Tier](https://github.com/markthedev12/aws-rds-secure-tier)**: Isolated, encrypted PostgreSQL tier built in Terraform, plus a Boto3 audit that verifies the controls actually hold.
* **[AWS EC2 DevSecOps Lab](https://github.com/markthedev12/aws-ec2-devsecops-lab)**: Terraform provisioned web server paired with a Python audit that flags security groups exposed to the internet.
* **[Secure AWS S3 Architecture](https://github.com/markthedev12/aws-secure-s3-lab)**: Hardened S3 with least privilege IAM, SSE encryption, an HTTPS only bucket policy, access logging, and CloudTrail.

**Identity & Access**
* **[IAM Access Review Bot](https://github.com/markthedev12/iam-access-review-bot)**: Compares access exports against role baselines, flags stale entitlements, and generates risk scored HTML reports.

**Infrastructure as Code**
* **[Route 53 DNS Failover](https://github.com/markthedev12/aws-route53-dns-failover-terraform)**: Active/passive DNS failover with Route 53 health checks, fully managed in Terraform.
